Import products from CSV

Columns: name, category, model, description, price, specs. Write specs as Power: 3 kW | Size: 600 mm. New categories are created automatically. Add photos afterwards by editing each product.

Bulk photo upload

Select many photos at once. Each file is matched to a product by its file name, which should be the product's model code or its exact name (for example KH-GR4.jpg). For extra photos of the same product, end the name with -2, -3 or -4 (for example KH-GR4-2.jpg). A product holds up to 4 photos.

Speed up existing photos

Find duplicates

Finds products that look like the same item, usually from repeated rows in the stock report. Check each group, choose the one to keep, and merge: photos, specs and any missing details from the others are moved into it, then the others are deleted.
